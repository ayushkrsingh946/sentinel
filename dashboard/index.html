The Judge Step: Evidence Verification & Disagreement Reconciliation

When small models hallucinate, they often invent line numbers or fabricate functions. Sentinel's Judge step performs strict evidence verification: every finding where the quoted evidence is absent from the actual source file is discarded. Disagreements are weighed, deduplicated, and resolved into an evidence-backed unified verdict.

Integration Guide: From Zero to Full Defense

Step-by-step numbered instructions with copy-paste commands to deploy Sentinel in your projects.

1

Install Sentinel & Pull Local Models

Sentinel runs 100% locally with Ollama. No API keys or cloud accounts required.

# 1. Install Ollama and pull open-weight models ollama pull llama3.2:3b ollama pull qwen2.5:0.5b ollama pull smollm2:135m # 2. Install Sentinel CLI pip install sentinel-security # Or clone and install editable: git clone https://github.com/ayushkrsingh946/sentinel.git && cd sentinel && pip install -e .
2

Configure Scope Allowlist (`sentinel.scope.yml`)

Sentinel non-negotiably enforces scope allowlists. It will refuse to scan or probe unauthorized paths or hosts.

# sentinel.scope.yml version: 1.0 allowed_targets: - "localhost" - "127.0.0.1" - "staging.local" allowed_paths: - "." - "src" - "packages"
3

Run Your First Audit & Diff Check

Scan source code or compare dependency updates before committing.

# Scan codebase sentinel scan src/ --threshold 60 # Audit dependency update diff sentinel diff package.json.orig package.json.new # Run Safe Staging Probe sentinel probe http://localhost:8080
4

Add GitHub Action CI Workflow

Fail pull requests when risky code or tampered dependency updates are pushed.

# .github/workflows/sentinel.yml name: Sentinel Audit on: [pull_request] jobs: audit: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: ayushkrsingh946/sentinel@main with: path: "." max-risk-score: 60
5

Attach Background Guard Middleware (FastAPI & Express)

Monitor-only by default! Watches traffic for injection patterns, scanner fingerprints, and path traversals.

# FastAPI / Python from fastapi import FastAPI from sentinel.guard.fastapi_middleware import SentinelGuardMiddleware app = FastAPI() app.add_middleware(SentinelGuardMiddleware, mode="monitor", block_threshold=70) # Express / Node.js const { SentinelExpressGuard } = require('sentinel-guard-middleware'); const guard = new SentinelExpressGuard({ mode: 'monitor' }); app.use(guard.middleware());

Responsible AI Disclosure & Operational Limits

Honest security documentation: Sentinel reduces risk, but is not an infallible shield.

Core Safety Rails (Non-Negotiable)

  • Static Analysis Only: Sentinel never executes scanned package code or download lifecycle scripts.
  • Automated Secret Redaction: AWS credentials, GitHub tokens, JWTs, and database URLs are scrubbed before prompt construction.
  • Scope Guard: Probing or scanning targets outside sentinel.scope.yml is strictly rejected.
  • Human-in-the-Loop Fixes: Policy defaults to manual approval. Automated patches always back up files and roll back on test failure.

Honest System Limitations

  • Small Model Noise: Sub-10B open-weight models may exhibit false positives on complex metaprogramming. The Judge step filters evidence, but manual review is always advised.
  • Zero-Day Novelty: Novel attack vectors with zero precedent in training data may bypass pattern checks.
  • Dynamic Payloads: Code compiled into binary blobs or fetched dynamically at execution time requires complementary runtime sandbox monitoring.
